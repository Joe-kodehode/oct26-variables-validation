Validation, Accessibility and SEO

In real projects, we must check that our code is correct, accessible and understandable.

HTML Validation

HTML Validation checks if your code follows the correct rules.

Errors in code can cause sites to break or behave unexpectedly.

Common mistakes:

  • Missing closing tags
  • Incorrect nesting (div inside p)
  • Missing alt attribute on images

W3C Validator

The W3C validator checks if you HTML is correct.

Go to: https://validator.w3.org/

You can paste your url, code or upload your file.

Accessibility checking

Accessibility means your website works for everyone, including people who use screen readers for example.

In many countries, incling Norway, accessibility is required by law.

Useful accessibility tools:

  • Lighthouse (built into Chrome devtools)
  • WAVE (wave.webaim.org)
  • axe DevTools (browser extension)

What these tools check

  • Missing alt text
  • Low color contrast
  • Missing labels in forms
  • Incorrect heading structure

SEO Basics

SEO (Search Engine Optimization) helps search engines understand your website.

Important SEO elements

  • Title: Shown in browser tab
  • Meta Description: short page summary
  • Headings: organizes our content
  • Alt text: helps describe images

Color Contrast
